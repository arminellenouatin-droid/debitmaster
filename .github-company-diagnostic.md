## Objectif

Identifier le code d’erreur Supabase réel lorsque la création d’un établissement échoue en production.

## Sécurité

Le serveur journalise uniquement le code, le hint et le message technique non secret. La réponse publique conserve le message utilisateur et expose un diagnostic catégorisé, sans clé ni donnée d’authentification.

## Vérification

- `pnpm exec tsc --noEmit`
- `pnpm run build`

Après fusion, redéployer Production puis effectuer un seul essai de création d’établissement afin de récupérer la catégorie exacte de l’erreur.
